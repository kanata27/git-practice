# CI/CD Basics

CI/CD automates the process of checking, building, and delivering an application.

## Continuous Integration

Continuous Integration automatically checks new changes in the repository.

## Continuous Delivery

Continuous Delivery prepares verified application changes for deployment.

## Typical Pipeline

1. Download the source code
2. Install dependencies
3. Run tests
4. Build the application
5. Build a Docker image
6. Deploy the application

## DevOps Connection

CI/CD connects source code, automated testing, Docker images, and deployment infrastructure.
